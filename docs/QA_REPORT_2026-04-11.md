# Lane4 QA Report

Date: April 11, 2026

Authoritative test target: `http://127.0.0.1:8765`

Important note: port `5001` was already serving a stale Gunicorn instance whose behavior did not match the checked-out repo. Findings below are based on the fresh server launched from this workspace on `8765`.

## What I tested

- New-user onboarding with manual time entry
- Account creation and login
- Explore results after onboarding
- Natural-language search
- Deep Dive generation
- Coach email generation
- Add to My List
- My List list view
- My List map view
- Reminder creation and reminders tab
- Real profile page and profile navigation
- Local persistence to SQLite

## Confirmed Bugs

### 1. Deep Dive latency is too high for a primary action

- Deep Dive took about `35.1s` to render in-browser for Denison.
- A direct backend call for Johns Hopkins took about `39s`.
- This is not a crash, but it is slow enough to feel broken for many users unless there is a much stronger loading experience or the request is made asynchronous.

Impact:
- High. Deep Dive is one of the app's flagship features and users are likely to click it early.

### 2. Coach email generation is also slow enough to create trust issues

- Coach email did return successfully, but only after a long wait.
- In the test pass, it was still loading for roughly `25s` before usable output appeared.

Impact:
- Medium to high. The feature works, but the wait is long enough that some users will assume it failed.

### 3. Profile navigation is easy to misread as a normal tab

- Clicking `Profile` in the top nav opens a dropdown, not the profile screen.
- The actual profile page requires a second click on `My Profile`.
- In testing, this was easy to mistake for a broken tab because the screen stayed on Reminders while the small dropdown appeared in the corner.

Impact:
- Medium. This is a real navigation trap, especially on first use.

### 4. Local API auth is awkward outside a real browser because the session cookie is `Secure`

- Browser-based localhost testing worked.
- `curl` and `requests` did not stay authenticated over plain `http://127.0.0.1`, because the session cookie is marked `Secure`.

Impact:
- Low for end users, medium for local QA/dev workflows.

## Inconveniences / UX Friction

### 1. Academic editing is not very discoverable

- The profile page surfaces `+ Add GPA`, `+ Add SAT`, and `+ Add APs` as small inline controls.
- This works, but it is much less obvious than a clear `Edit academics` button.

### 2. Search results leave a lot of empty canvas

- The search query tested returned strong results quickly, but only `3` cards were visible.
- The page then left a large amount of blank space, which makes the product feel thinner than it is.

### 3. My List print actions are de-emphasized

- `Print List (Cards)` and `Print with Deep Dives` are useful, but visually tiny and easy to miss.

### 4. List strength language can feel harsher than necessary

- The `HIGH RISK` warning is useful, but the copy is blunt.
- Advising-oriented users may appreciate it; anxious high school families may feel judged by it.

## What worked well

### 1. Onboarding is fast and clear

- Manual fallback worked cleanly.
- After entering just two times, the app produced `6` immediate fit cards.

### 2. Search felt genuinely useful

- Query tested: `best hidden ivies where I can swim`
- Search returned in about `2.5s`.
- Results felt coherent and included swim and admissions framing.

### 3. Deep Dive quality is strong

- The Deep Dive layout is one of the app's best surfaces.
- The `Bottom Line`, admissions comparison table, cost framing, and expandable sections are all compelling.

### 4. Coach email is very marketable

- The generated subject line was polished and credible:
  `Prospective Student-Athlete Inquiry — Class of 2026 | Competitive Swimmer`

### 5. My List ecosystem is promising

- List view, map view, reminder creation, and the recruiting-stage model all worked.
- This creates a real sense that Lane4 is not just search, but a recruiting workflow tool.

## Strongest Features To Market

### 1. Instant swim-fit discovery from real times

- The app turns a swimmer's actual times into immediate school-fit results.

### 2. AI search that understands recruiting intent

- The tested search handled a nuanced query and returned schools that felt meaningfully curated, not random.

### 3. Decision-ready deep dives

- The Deep Dive combines swim fit, admissions reality, cost framing, and campus narrative in one screen.

### 4. Coach outreach drafting

- This is tangible, practical value for families who do not know what to say to coaches.

### 5. Built-in recruiting organizer

- My List, reminders, stage tracking, and map view make the app feel like a real operating system for the process.

## Recommended next moves

1. Reduce Deep Dive and coach-email latency, or make both asynchronous with stronger progress states.
2. Make `Profile` a direct destination, or rename the nav item so users know it is a menu.
3. Add a more explicit academic edit control on the profile page.
4. Give search results a denser continuation state so broad queries do not end in lots of whitespace.
5. Promote the print/export actions more clearly in My List.

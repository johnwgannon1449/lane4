GOAL

Update the scoring model to use the swimmer’s TOP 4 scoring events instead of TOP 3.

--------------------------------------------------
CURRENT BEHAVIOR
--------------------------------------------------

rawPts is currently computed as:
- sum of pts from top 3 events

top3 array is:
- sorted events by pts descending
- first 3 used

--------------------------------------------------
NEW BEHAVIOR
--------------------------------------------------

1. Replace top3 logic with top4:

- sort allEvents by pts descending
- take top 4 events instead of 3
- compute rawPts as sum of top 4 event pts

2. Maintain backward compatibility:

- If swimmer has fewer than 4 scoring events:
  - use all available events (no errors)

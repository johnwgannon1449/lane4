PART 5 — WINNER-AWARE MULTI-SELECTION
=====================================

The curator should support multiple selected images in a category.

New rule:

* the first selected image in a category is the WINNER
* winner status is order-based
* winner must be stored and restored

Behavior example:

* select A, then B, then C
* ordered selection list = [A, B, C]
* winner = A

If A is deselected:

* ordered selection list = [B, C]
* winner = B

If A is selected again later:

* ordered selection list = [B, C, A]
* winner remains B unless B is removed

Apply this to:

* campus / hero
* pool
* student_life too if easiest for consistency

Important:
I may select multiple hero images and multiple pool images.
The first selected is the true winner and will be used differently later, especially hero winner #1.

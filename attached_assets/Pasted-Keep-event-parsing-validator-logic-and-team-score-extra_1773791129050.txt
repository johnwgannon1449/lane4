Tier framework to use (locked)

1) Compute within each conference + gender table:
- champion_score
- total_meet_points
- champion_ratio = score / champion_score
- meet_share = score / total_meet_points

2) Base tiers come from champion_ratio:
- Tier 1: champion_ratio >= 0.85
- Tier 2: 0.60 <= champion_ratio < 0.85
- Tier 3: 0.35 <= champion_ratio < 0.60
- Tier 4: champion_ratio < 0.35

3) Split Tier 1 using meet_share:
- if meet_share >= 0.24 => Tier 1A (Super Powerhouse)
- else => Tier 1B (Powerhouse)

4) Do NOT combine champion_ratio and meet_share into one blended score.
ChampionRatio determines base tier.
MeetShare only distinguishes Tier 1A vs Tier 1B.

D) Deterministic outputs
Make the tiering run deterministic:
- same input should produce same outputs every run
- stable sorting by conference, gender, rank, score desc, team

E) Graceful failure

- record the reason in a QA file
- continue processing the rest

F) QA outputs

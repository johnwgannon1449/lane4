PART 3 — PATRIOT: PAGE-CONTINUATION + EVENT CONTEXT
==================================================

Observation:
Patriot events span pages and include continuation headers like:

- "Preliminaries ... (#7 Men 500 Yard Free)"
- "A - Final ... (#24 Men 100 Yard Back)"

Problem:
Event context is being lost across pages and sections.

Implement:

1. Continuation detection
   - detect "(#N Event Name)" inside continuation lines
   - treat as authoritative event identity

2. Context carry-forward
   - when a page starts mid-event, preserve event context
   - do NOT reset event on page breaks

3. Section awareness
   Recognize:
   - Preliminaries
   - A Final
   - B Final
   - C Final
   - straight results sections

4. Event merging
   - multiple sections of same event must merge into one event object
   - do NOT treat each section as a separate event

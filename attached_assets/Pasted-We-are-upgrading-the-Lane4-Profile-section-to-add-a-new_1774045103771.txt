We are upgrading the Lane4 Profile section to add a new set of personalization questions and make their responses save properly.

IMPORTANT
This change is about the Profile/preferences experience only.
Do NOT change:
- admissions logic
- swim/recruiting logic
- search logic (yet)
- deep dive narrative logic
- onboarding flow unless needed only to support shared preference state
- existing swimmer bio / event time save behavior unless required for integration

GOAL
Add a clean “Preferences” section to the Profile area where users can answer personalization questions that will later support search and deep dives.

Also add a real Save button for this section so users can save/update their responses intentionally.
